## Описание проекта

Сервис решает задачу построения эталонного справочника должностей на основе "сырых" данных и последующей классификации. 

**Что уже сделано:**
- Очищены и нормализованы "сырые" названия должностей
- Построен эталонный справочник на основе кластеризации
- Система классифицирует новые должности с помощью семантического поиска
- Система предоставляет веб-интерфейс 

**Результаты:**
- 7 770 уникальных должностей приведены к 62 эталонам
- Покрытие классификацией — **99.4%**
- Семантический поиск понимает синонимы

# Классификатор НСИ по должностям

## Обработка сырых данных в Google Collab 

1. **Очистка и нормализация** (`clean_position_name`)
   - Удаление мусора (скобки, цифры, спецсимволы)
   - Исправление опечаток (`typos`)
   - Расшифровка сокращений (`зам.` → `заместитель`)
   - Удаление географии (`remove_geography`)
   - Приведение к нижнему регистру + капитализация

2. **Выделение атрибутов** 
   - `category` — категория (1, 2, 3, 4, высшая, без)
   - `rate` — ставка (0.5, 0.25 и т.д.)
   - `harm` — вредность (24%, 20%)
   - `rank` — разряд (6, 5, 4)

3. **Векторизация** (TF-IDF)
   - Биграммы `(1, 2)`

4. **Кластеризация** (KMeans)
   - **Оптимальное число кластеров подобрано через silhouette_score**
   - Диапазон 100–3000, шаг 200
   - Силуэт растёт, плато достигается в диапазоне 2000-2400
   - **Выбрано `n_clusters=2200`** 

5. **Объединение кластеров**
   - **Auto merge**
   - **Semantic merge с порогом 0.92** 
   - **Merge по словарю синонимов**

##  Как это работает?

1. Обработка данных (Google Colab)
- Очистка текста: удаление мусора, нормализация сокращений
- Векторизация с помощью TfidfVectorizer
- Кластеризация методом K-Means (оптимальное число = 62)
- Генерация эталонов 

2. Классификация (Веб-сервис)
- Пользователь вводит название должности
- Запрос преобразуется в эмбеддинг 
- Вычисляется косинусное расстояние с эмбеддингами эталонов
- Возвращается ближайший эталон 

3. Архитектура
- Эмбеддинги эталонов хранятся в PostgreSQL
- Логирование всех запросов для анализа
